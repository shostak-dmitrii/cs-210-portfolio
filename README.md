# cs-210-portfolio
Portfolio for Southern New Hampshire University CS-210. Contains my C++ project
## Corner Grocer Project
This project is for the Corner Grocer store. The problem was they had a big list of items bought every day but they didn't know how many of each item they sold.

My program reads the file and counts everything so they can see which item is popular.

I think I did map part really well. It was very easy to use the map to count the words and it keeps everything in ABC order without me doing extra work.

To make the code better or more efficient, I could probably add more error checks for the files or the user input. It'd be more secure if I checked every single character the user types so they can't break the program.

The most challenging part for me was being Mac user. The input file had Windows carriage returns that made my code act unexpected. I had to trim those characters with pop_back. My support network was definitely the professor, class resources and AI debugging tools.

The skills I learned here like using classes and maps are very transferable I guess. I'll definitely use maps again in future projects when I need to store data  and find it fast.

I made the program maintainable by using a class. This makes it readable because the main menu is short and the logic is inside the groceryClass file. I also added comments everywhere so it's easy to adapt later if the store wants more features.
